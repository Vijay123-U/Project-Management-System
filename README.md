# Project Management System

A web-based Project Management System developed using Spring Boot, Thymeleaf, Bootstrap, and MySQL.

## Features

- Employee Management
  - Add employees
  - View employees
  - Edit employees
  - Delete employees

- Project Management
  - Add projects
  - Assign projects to employees
  - View projects
  - Edit projects
  - Delete projects

- Task Management
  - Add tasks
  - Assign tasks to projects
  - Track task status
  - View tasks
  - Edit tasks
  - Delete tasks

- Employee Work Report
  - View employee
  - View assigned project
  - View assigned task
  - View task status

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Thymeleaf
- Bootstrap
- MySQL
- Maven
- HTML/CSS
